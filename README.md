# 🏡 NGO — BASTI KI PATHSHALA

"Basti Ki Pathshala Foundation is a nonprofit initiative committed to providing quality education to children in underserved communities, especially those living in slum or basti areas. The organization aims to bridge the educational gap by offering access to learning resources, mentoring, and a supportive environment. Through collaboration with volunteers, donors, and community members, Basti Ki Pathshala empowers children by helping them develop academic skills and confidence, so that they can envision and pursue brighter futures."

A clean, responsive NGO website built to inform, inspire, and mobilize support for education in underserved communities. Includes core sections requested by the client plus extended pages to convey mission, impact, and ways to get involved.

## ⚙️ Getting Started

1. Clone the repository

```bash
   git clone https://github.com/VivekChauhan1807/NGO-Basti-Ki-Pathshala.git
   cd ngo-project
```

2. Install dependencies

```bash
   npm install
```

3. Start development server

```bash
   npm run dev
```

---

## 📦 Build and Deploy

- Build for production

```bash
  npm run build
```
- Deployed on Netlify using the production build.
